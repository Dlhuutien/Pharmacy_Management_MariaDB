# Pharmacy Sales Management System

## Overview
- Developed a desktop-based pharmacy sales management system for a private pharmacy using Java. The application supports managing medicine inventory, suppliers, customers, employees, user accounts, invoices, and sales statistics. Implemented role-based access for managers and sales staff, and designed a friendly Java Swing GUI for ease of use. Integrated MariaDB for data storage and used Java Persistence API for data access.
---

## Features

- **User Authentication & Role Management**  
  - Manager & staff login  
  - Automatic account creation for employees  
  - Password change functionality  

- **Medicine Management**  
  - Add, edit, delete, search medicines  
  - Manage suppliers and drug expiration  
  - Categorize prescription vs non-prescription drugs  

- **Sales & Invoices**  
  - Create invoices  
  - Add multiple medicines per invoice  
  - View and search past invoices  
  - Auto-calculate totals

- **Statistics Dashboard**  
  - Daily sales reports  
  - Top-selling drugs  
  - Employee performance tracking

---

## 🛠Technologies Used
- **Language:** Java  
- **GUI:** Java Swing  
- **Database:** MariaDB  
- **ORM:** Java Persistence API (JPA)  
- **Modeling:** UML (Use-case diagram, Class diagram, Entity-Relationship Diagram – ERD)
